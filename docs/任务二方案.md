## 0. 一页纸摘要

**目标**：用一组有主张、可复现、可印刷的图表，回答 128 年奥运史的四组问题——奖牌格局如何膨胀与固化、国家如何崛起与坠落、女性如何从 0 走到 49.1%、项目如何生灭更替——并让读者清楚看到“口径如何改写答案”。

**交付**：

1. 交互数据故事站（ECharts，滚动叙事 + 全局口径切换）；
2. 报告用高清图资产（PNG@4x + SVG）；
3. 离线单文件包（评委无网络可打开）；
4. 每图图注、≥100 字解读、口径徽章；
5. 90 秒视频分镜与录屏素材；
6. 海报主图素材与图表组件库（供任务四复用）。

**核心策略**：

- **6 幅必做 + 2 幅应做 + 2 幅可选**，主图内做复合面板，丰富度靠信息密度而不是图的数量；
- **一条叙事脊柱**：“百年奥运是一部扩张史，也是一部集中史；口径决定你看到哪一面”；
- **双口径并置**：小项口径与运动员行口径同时呈现，并给出排名敏感性面板；
- **双主题**：站点深墨绿，PDF/海报强制浅色；
- **ECharts 单栈**：甘特、哑铃、河流图都用 ECharts 实现，删除无法诚实映射的世界地图。

**关键数字（用于对账）**：

| 指标 | 数值 |
| --- | --- |
| 参赛记录总数 | 252,565 行 |
| 奖牌记录 | 38,818 行（金 13,002 / 银 12,746 / 铜 13,070） |

| NOC | 234 个（157 个曾获奖，77 个从未获奖） |
| 体育大类 | 76 种（存在 2020 年前后漂移） |

| 2020 / 2024 官方小项数 | 339 / 329（用于交叉校验） |

**关键决策记录**：

| 议题 | 决定 | 理由 |
| --- | --- | --- |
| 图表数量 | 6 + 2 + 2 | 14 幅会稀释论点，6 幅无法体现丰富度，中间值最稳 |
| 世界地图 | 删除，移交任务四 | 历史政体无法映射到现代国界，且无人口归一后信息量低 |
| 深色主题 | 站点深色 + 印刷浅色 | 深色直接打印会成黑页，灰度对比失效 |
| 全局口径开关 | 2 套预设 + 1906 开关，仅 6 幅联动 | 4 状态 × 14 图联动极易漏改，造成口径事故 |
| 甘特 / 哑铃 / 河流 | 甘特 P0，河流 P1，哑铃 P2 | 甘特直接回应赛题“消失/新增”，后两者边际收益较低 |
| 2020+ 小项 | 区间估计 + 官方校验 | Event 泛化无法精确还原，不能画虚假连续曲线 |
| 外部数据 | 任务二不使用 | 核心结论必须仅凭赛题数据集复现；GDP/人口留给任务三 |

## 2. 总体设计

### 2.1 一个仓库，三种交付

| 交付物 | 形式 | 用途 |
| --- | --- | --- |
| 交互数据故事站 | Vite + TypeScript + ECharts，单页滚动叙事 | 路演、线上展示、任务四复用 |
| 报告图资产 | 每图 PNG@4x + SVG，自动编号导出 | 直接插入 20 页 PDF |
| 离线包 | 单文件 `olympics-story.offline.html` | 评委无网络可打开 |

数据管线用 Python 预聚合，前端只加载聚合后的 JSON。252,565 行原始数据不进入浏览器。

### 2.2 设计原则

1. **一个主张一张图**：每幅图标题就是结论，图只证明这一句话。
2. **口径先于图**：先定分母、口径、1906 处理，再选图型。
3. **静态可读优先**：报告里的静态图必须脱离交互仍能读懂；交互只是加分。
4. **不做图表堆砌**：同一主张不重复画第二张图；用面板补充而不是加图。
5. **单栈 ECharts**：所有图表、地图（若任务四需要）、甘特、哑铃、河流图都用 ECharts。

### 2.3 叙事脊柱

> **百年奥运是一部扩张史，也是一部集中史；口径决定你看到哪一面。**

四视角不是并列关系，而是同一矛盾的四次追问：

| 章节 | 张力 | 结论方向（待数据验证） |
| --- | --- | --- |
| 序 | 从 380 行到 14,892 行 | 规模扩张是百年主线 |
| 一 奖牌版图 | 奖牌在膨胀，榜首是否在固化 | 总量膨胀，头部集中度未必下降 |
| 二 国家沉浮 | 新国家崛起，旧强国是否仍垄断 | 四种国家模式并存 |
| 三 她的奥运 | 女性从 0 到半数，产出是否同步 | 参与平权 ≠ 产出平权 |
| 四 项目生灭 | 项目不断更替，核心是否稳定 | 核心稳定、边缘轮换 |
| 五 口径之辩 | 换一种口径，结论会不会翻转 | 排名是口径的函数 |

## 4. 图表方案

### 4.1 图表总表

| ID | 图名 | 优先级 | 必选视角 | ECharts 实现 | 核心主张 / 待检验假设 |
| --- | --- | --- | --- | --- | --- |
| A1 | 双口径总榜 + 排名敏感性 | P0 | A 奖牌格局 | 横向堆叠 bar + slope 小面板 | 排名是口径的函数 |
| A2 | 逐届演变 + 膨胀指数 | P0 | A 奖牌格局 | `timeline` + bar race；报告版 4 个静态快照 | 膨胀来自小项与参赛规模，不是单国产出 |
| B1 | 九国命运矩阵 | P0 | B 国家兴衰 | 单实例多 `grid` + `line`，3×3 | 四种国家模式并存 |
| C1 | 她的奥运双弧线 | P0 | C 她的奥运 | 堆叠面积 + 第二 grid 折线 | 0%→49.1% 是三次制度跃迁，不是线性增长 |
| C2 | 参与 ≠ 产出 | P0 | C 她的奥运 | `scatter` + 对角线 + 象限 `markArea` | 女性参赛占比高不等于女性奖牌占比高（待检验） |
| D1 | 项目生命线 | P0 | D 项目演化 | bar range（ECharts 6）或 `custom` 兜底 + `dataZoom` | 核心稳定、边缘轮换 |
| B2 | 国家效率前沿 | P1 | B 国家兴衰 | 双 log `scatter` + `effectScatter` | 参赛规模与奖牌非线性，小国位于效率前沿 |
| D2 | 项目结构变迁 | P1 | D 项目演化 | `themeRiver`，6–8 类 + Other | 核心大类份额稳定，新兴类上升 |
| X1 | 国家×项目优势矩阵 | P2 | B 国家兴衰 | `heatmap` + `visualMap` | 传统优势的路径依赖 |
| X2 | 项目性别差哑铃 | P2 | C 她的奥运 | `custom` 或双 scatter + 连接线 | 哪些项目性别差距最大 |

**满足必选要求**：A（A1、A2）、B（B1、B2）、C（C1、C2）、D（D1、D2），每视角至少 1 幅核心图，实际每视角 2 幅。

### 4.2 P0 图表详设

#### A1 双口径总榜 + 排名敏感性

- **目标**：回答“谁在统治奖牌榜”，并证明“排名会随口径改变”。
- **主图**：历史总奖牌 Top 20 横向堆叠条形，金/银/铜固定色；每国右侧标注金牌数。
- **敏感性面板**：Top 10 在 4 种定义下的排名 slope 图：
  1. 运动员行口径（含 1906）；
  2. 运动员行口径（不含 1906）；
  3. 保守小项口径（不含 1906）；
  4. 宽松小项口径（不含 1906，2020+ 取上界）。
- **关键注释**：2024 年美国官方 40 金 vs 本数据 131 个金牌行；荷兰官方 15 金 vs 67 个金牌行。差异来自团体项目按人计行。
- **交互**：全局口径切换时用 `universalTransition` 重排；悬停显示“该国奖牌行 / 去重后奖牌 / 差额”。
- **报告版**：主图 + 敏感性面板并排，占 1 页。
- **口径**：保守小项口径为主，运动员行口径对照；不含 1906；团体项目每国每小项每色计 1 枚。
- **验收**：Top 10 在 4 种定义下的排名变化必须写入图注；任何排名翻转都要有解释。

#### A2 逐届演变 + 膨胀指数

- **目标**：把“逐届奖牌榜演变”和“奖牌通货膨胀”压进一幅图。
- **交互版**：`timeline` + bar race，播放 1896–2024，每届显示事件级奖牌 Top 10；固定 NOC 颜色映射，只显示 8–10 条。
- **报告版**：4 个静态快照（1896、1960、2000、2024）小倍数 + 膨胀指数折线面板。
- **膨胀指数**：奖牌总数、代表团数、参赛人数、小项数，均以 1896=100 指数化；2020+ 小项数用代理并标注。
- **关键注释**：1916/1940/1944 停办；1980/1984 抵制；2020 东京延期但记为 2020。
- **交互**：播放/暂停/拖动；点击国家高亮其在其他届次的表现。
- **口径**：事件级奖牌；不含 1906；抵制届留白，不画 0。
- **验收**：报告版静态快照能独立说明“头部国家变化不大，总量在膨胀”。

#### B1 九国命运矩阵

- **目标**：用 9 个面板回答“国家如何兴衰”，满足 ≥8 国要求。
- **国家池**：美国、苏联谱系（URS/EUN/RUS/ROC/AIN）、德国谱系（FRG/GDR/GER）、中国、日本、韩国、英国、澳大利亚、匈牙利。
- **图形**：单实例 3×3 多 `grid`，每面板总奖牌折线 + 金牌折线，共享 axisPointer；各自 y 轴独立。
- **关键注释**：苏联 1988 最后一届、EUN 1992、ROC 2020、AIN 2024；两德 1968–1988 分立、1992 统一；中国 1984 首次大规模参赛、2008 主场；日本 1964/2020；韩国 1988；英国 2012；澳大利亚 2000。
- **交互**：悬停联动显示同届各国；点击面板放大。
- **报告版**：3×3 矩阵占 1 页，中国拆解作为 inset（1984 以来按项目类别堆叠）。
- **口径**：事件级奖牌；不含 1906；政体按 NOC 原样呈现，谱系只在注释层连接，不在主数据合并。
- **验收**：每个面板至少 2 个注释；读者能从中识别出四种国家模式。

#### C1 她的奥运双弧线

- **目标**：呈现女性参与 0%→49.1% 的百年弧线，并解释“不是线性增长”。
- **主图**：男性/女性参赛人数堆叠面积 + 女性占比折线（第二 grid 或双轴，优先第二 grid）。
- **里程碑注释**：1900 首批女性参赛；1928 阿姆斯特丹田径/体操向女子开放；1960 罗马；1984 洛杉矶；2012 伦敦所有项目设女子小项；2024 巴黎 49.1%。
- **辅助面板**：女子小项与混合小项数量变化（Sport×Sex 口径，2020+ 标注估计）。
- **稳健性检查**：运动员行口径可能被团体项目抬高，附一个“代表团层面女性参与”的小注或脚注。
- **交互**：悬停显示该届男女记录数与占比；点击里程碑跳转。
- **报告版**：主图 + 里程碑条，占 1 页。
- **口径**：运动员行口径为主，分母为全部参赛记录；不含 1906；2020+ 小项用 Sport×Sex 估算并标注。
- **验收**：至少 4 个里程碑；图注说明分母与团体项目影响。

#### C2 参与 ≠ 产出

- **目标**：检验一个可能“推翻直觉”的假设：女性参赛占比高的国家，女性奖牌占比是否同步高。
- **图形**：散点图，X = 女性参赛占比，Y = 女性奖牌占比，对角线 y=x；点大小 = 总奖牌数；颜色 = 大洲/区域。
- **象限**：`markArea` 标出“高参与高产出”“高参与低产出”“低参与高产出”“低参与低产出”。
- **重点标注**：美国、中国、荷兰、牙买加、印度等。
- **数据定义**：
  - 女性参赛占比 = 该国该届女性运动员行 / 全部运动员行；
  - 女性奖牌占比 = 该国该届女性奖牌行 / 全部奖牌行；
  - 混合项目单列，不并入男女；
  - 可做 2024 单届，也可合并近三届以提高样本量。
- **假设检验**：先跑数据，若大多数国家位于对角线附近或假设不成立，立即换 B2 为 P0，不硬讲故事。
- **交互**：悬停显示国家、占比、奖牌数、偏离对角线幅度；可切换单届/近三届。
- **报告版**：散点 + 四象限 + 3 个标注，占 1 页。
- **口径**：运动员行口径；混合项目单列；不含 1906。
- **验收**：必须给出“哪些国家显著偏离对角线”的具体名单与幅度；若假设失败，记录失败结论并换图。

#### D1 项目生命线

- **目标**：直接回应赛题“消失的运动与新增的运动”，一张图看百年项目生灭。
- **主图**：横向甘特/生命线，每个 `sport_norm` 一条，从首次出现到最近出现；按首次年份排序；颜色区分“仍在”“已消失”“新增”。
- **顶部轴**：每届小项数柱/线，2020+ 用 Sport×Sex 代理并加不确定带，叠加官方 339/329 校准点。
- **高亮**：拔河（1900–1920）、槌球（1900）、马球、艺术竞赛（1912–1948）、1908/1920 夏奥花样滑冰、1920 冰球；新增：跆拳道（2000）、七人制橄榄球（2016）、滑板/冲浪/攀岩（2020）、霹雳舞（2024）。
- **交互**：`dataZoom` 横向缩放；悬停显示首次/最近年份、参赛届数、奖牌数；点击高亮该项目在所有图表中的出现。
- **报告版**：生命线占 1 页，顶部小项数轴与生命线共图。
- **口径**：事件级小项；2020+ 小项数为估计值；不含 1906；1908/1920 的冬季项目按数据原样保留并注释。
- **验收**：至少标出 6 个消失项目与 5 个新增项目；2020+ 估计值必须有视觉区分（虚线/斜纹/不确定带）。

### 4.3 P1 / P2 图表

| ID | 说明 | 触发条件 |
| --- | --- | --- |
| B2 国家效率前沿 | X = 场均参赛人数（log），Y = 场均事件级奖牌（log），点大小 = 参赛届数；标注 JAM/KEN/HKG/NZL/BAH/CUB；不引入 GDP/人口 | P0 完成后有余力，或 C2 假设失败时顶替 |
| D2 项目结构变迁 | `themeRiver`，只放 6–8 个大类 + Other；按奖牌事件份额 | D1 完成后有余力 |
| X1 国家×项目优势矩阵 | Top 12 NOC × Top 10 `sport_norm`，值为 lift（该国该项目奖牌份额 / 该国全部奖牌份额） | 时间充足，且矩阵可读性通过评审 |
| X2 项目性别差哑铃 | 2024 各项目女性小项占比 vs 男性小项占比，按差值排序 | 时间充足，仅作 C 视角补充 |

### 4.4 图表规范

- **标题**：结论式主标题 + 口径副标题。例：“奖牌榜是口径的函数” / “保守小项口径 · 不含 1906 · 团体项目计 1 枚”。
- **坐标轴**：必须写单位；对数轴必须标注 `log`；不使用无必要的双轴。
- **颜色**：金/银/铜固定；金色不能作为唯一编码，奖牌类型同时用位置/标签/纹理区分；提供色盲安全辅助色。
- **注释**：每图 3–5 个关键注释，不堆满；注释文字不超过 20 字。
- **来源行**：数据版本 + 口径 + 生成日期，例：“数据 v1.0 · 保守小项口径 · 不含 1906 · 2026-11-25 生成”。
- **禁用**：3D 图、饼图、无信息量的装饰性地图、纯靠颜色区分胜负的图。
- **数字格式**：千分位；百分比保留 1 位小数；排名变化用“↑/↓ + 位次”文字，不只靠颜色。

## 5. 口径与数据契约

### 5.1 三种口径

| 口径 | 定义 | 用途 | 局限 |
| --- | --- | --- | --- |
| 运动员行口径 | 原始一行计 1 条记录；团体项目每位成员各计 1 | 展示“人”的规模，作为上界 | 团体项目严重膨胀，不可直接与官方奖牌榜比较 |
| 保守小项口径 | 按 `(Year, NOC, event_key, Medal)` 去重；团体项目每国每小项每色计 1 枚；2020+ 泛化 Event 取下界 | 主榜、趋势、国家对比 | 2020+ 可能低估 |
| 宽松小项口径 | 同上，但 2020+ 泛化 Event 取上界（按运动员行） | 敏感性面板、区间估计 | 2020+ 可能高估 |

**主口径**：保守小项口径。**对照口径**：运动员行口径。所有图必须在标题或脚注声明使用哪一种。

### 5.2 2020+ Event 泛化的区间估计（关键）

2020/2024 两届约 6,700 行（约 22–23%）的 Event 是 `Men` / `Women` / `Men Team` / `Relay Only Athlete` 等泛化值，无法逐小项还原。处理规则：

1. 任务一提供 `event_key` 与 `event_key_quality`（`specific` / `generic`）。
2. `specific`：按 `(Year, NOC, event_key, Medal)` 去重，团体项目计 1 枚。
3. `generic`：给出区间估计：
   - 下界 = 每个 `(Year, NOC, Sport_norm, Sex, Medal)` 组计 1 枚；
   - 上界 = 该组运动员行数；
   - 真实值落在区间内。
4. 用官方 2020/2024 奖牌数（如美国 40 金、荷兰 15 金）校验区间是否包含官方值；若不包含，回查数据或调整分组。
5. 主榜使用下界；A1 敏感性面板展示上界与运动员行口径下的排名变化。
6. D1 小项数同样使用 `Sport_norm × Sex` 代理，叠加官方 339/329 作为校准点，不画虚假连续曲线。

### 5.3 特殊记录处理

| 情况 | 处理 | 图注写法 |
| --- | --- | --- |
| 1906 届 | 默认排除；A1 敏感性面板可切换包含 | “不含 1906；含 1906 的对比见敏感性面板” |
| 1956 双城 | 墨尔本与斯德哥尔摩合并为 1956 届，注释说明马术分场 | “1956 含斯德哥尔摩马术分场” |
| 1980/1984 抵制 | 曲线留白，不画 0；注释抵制背景 | “1980/1984 抵制潮，曲线留白非零值” |
| 政体变迁 | 主图按 NOC 原样（URS/GDR/FRG 独立）；谱系只在注释层连接 | “政体按 NOC 原样呈现，未合并谱系” |
| 团体项目 | 小项口径每国每小项每色计 1 枚 | “团体项目计 1 枚，非按人数计” |
| 并列奖牌 | 不同 NOC 并列各计 1 枚；同 NOC 重复行去重 | “并列奖牌按 NOC 各计 1 枚” |
| 2020 东京延期 | 年份保留 2020，注释实际举办于 2021 | “2020 东京实际于 2021 年举行” |
| 2024 Sport 逗号拼接 | 任务一归一后再统计；未归一值不进入图表 | “Sport 已归一，原始逗号拼接值见任务一文档” |

### 7.2 数据管线

### 7.5 导出与离线包

## 附录 A：解读写作模板

固定四句式：

1. **结论句**：一句话说清这幅图证明了什么；
2. **数据证据**：给出 2–3 个关键数字或对比；
3. **机制解释**：为什么会出现这个模式；
4. **口径提醒**：分母、口径、1906、2020+ 限制、反例。

**示例（A1，约 160 字）**：

> 奖牌榜不是唯一答案，而是口径的函数。保守小项口径下美国长期居首；切换到运动员行口径后，荷兰等团体项目强国排名明显上升——2024 年荷兰官方 15 金，本数据却有 67 个金牌行。差异并非竞技水平变化，而是团体项目按人计行。值得注意的是，排名翻转主要集中在团体项目占比高的国家，中国、日本等以个人项目为主的国家相对稳定。口径：保守小项口径，不含 1906；四种定义下的排名变化见敏感性面板。
