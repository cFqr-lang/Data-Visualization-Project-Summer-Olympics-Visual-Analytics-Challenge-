## 2. 逐页内容

### P1 封面 + 摘要

**摘要草稿（298 字，可直接用）**

> 本作品以 1896–2024 年夏季奥运会 252,565 行参赛记录为底本，先解决数据本身的六类缺陷，再回答三个问题：奖牌榜在什么口径下才可信、百年格局如何演变、主场优势究竟是脉冲还是台阶。
>
> 审计发现两处足以改变结论的口径陷阱：2020 年起 Event 字段泛化会让小项口径少算 702 个奖牌单位，而按运动员行计数会把团体项目奖牌放大 2,840 枚。我们据此给出 strict 与 NOC-aware 两套口径，并让全篇结论同时接受两者检验。
>
> 在可信口径上，我们看到：女性参赛占比用 124 年从 1.7% 走到 49.1%，但"接近半数"在项目层并不成立；东道主加成真实存在——20 届中 19 届高于基准、中位增量 +13.3 枚——却在下一届即蒸发大半，指数从 163 回落到 112，本质是"多派人"而非"多夺牌"的一次性脉冲。
>
> 方法上全部图表由开源的 Python + ECharts 管线从原始 CSV 一键生成，无外部数据，可逐图复现。

**写作要点**：摘要只放结论，不放方法细节；三个数字（702、+13.3、163→112）是记忆锚点。

### P14 洞察与结论

三条主线，每条都要"双口径都成立"：
1. 口径决定榜首（P4 的回声）

3. 数量扩张 ≠ 质量提升（P11 机制）
