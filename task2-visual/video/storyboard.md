# 90 秒视频分镜 · 百年奥运全景

> 用途：交给视频负责人合拍。四个停顿分别对应 A1、B1、C1、D1，均为任务二图表。
> 总时长 90 秒；旁白语速按 4.2 字/秒估算。所有数字与 `report/figures.md` 一致。

## 0:00–0:08 开场

- **画面**：黑底，金色数字从 1896 快速翻到 2024；随后出现主标题「百年奥运，是一部扩张史，也是一部集中史」。
- **旁白**：一百二十八年，奥运从 12 个代表团，变成 206 个。
- **字幕**：1896 → 2024｜12 → 206 个代表团

## 0:08–0:24 第一停顿 · A1 奖牌榜是口径的函数

- **画面**：Fig.2-1 左图（Top 20 堆叠条形）从下往上生长；切到右图排名连线，镜头跟随 CHN 从第 7 升到第 4。
- **旁白**：同一场比赛，换一种数法，榜首就会改写。按运动员行计数，美国是五千五百九十七枚；按小项去重，只剩两千七百五十七枚。多出来的两千八百四十枚，几乎都来自团体项目的重复计数。
- **字幕**：USA 5,597 → 2,757（−2,840）｜CHN 第 7 → 第 4

## 0:24–0:40 第二停顿 · B1 九国命运矩阵

- **画面**：Fig.2-3 九宫格依次点亮：美国长盛、苏联谱系 1988 峰值、德国 1990 断裂、中国 1984 后抬升；镜头在苏联谱系与中国面板停留。
- **旁白**：国家不是一条曲线。美国几乎全程在线；苏联在 1988 年见顶，之后是独联体、俄罗斯、ROC 和 AIN；德国在 1990 年断裂又合并；中国从 1984 年起一路抬升。九宫格让我们看见四种命运，而不是一张总榜。
- **字幕**：长盛 / 骤起骤落 / 分立统一 / 后发崛起

## 0:40–1:00 第三停顿 · C1 她的奥运双弧线

- **画面**：Fig.2-4 男女堆叠面积展开，女性占比金色曲线从底部爬升；六个里程碑金点依次亮起，最后停在 49.1%。
- **旁白**：1900 年，女性只占参赛记录的百分之一点七；1928 年升到八，1960 年十七，1984 年二十六，2012 年四十五。2024 年，巴黎，四十九点一。不是直线，是三次跃迁。
- **字幕**：1.7% → 8.1% → 17.7% → 25.9% → 45.0% → 49.1%

## 1:00–1:18 第四停顿 · D1 项目生命线

- **画面**：Fig.2-6 小项数曲线拉高，339 / 329 两个官方校准点出现；镜头下移到生命线，早期项目熄灭、2020 年代新项目亮起。
- **旁白**：小项从 43 个涨到 336 个官方 329 个。核心项目一直在：田径、游泳、体操、赛艇、击剑。边缘项目不断轮换：马球、拔河、板球退场，三人篮球、攀岩、冲浪、霹雳舞进场。
- **字幕**：43 → 336（官方 329）｜稳定核心 + 轮换边缘

## 1:18–1:30 收束

- **画面**：八张图缩略图排成 2 × 4，最后回到主标题与数据来源。
- **旁白**：扩张的是规模，集中的是头部。百年奥运，两组力量同时发生。
- **字幕**：数据 1896–2024 · 任务二 · Apache ECharts

## 制作提示

- 图表素材：`exports/png/` 下 8 幅 4x PNG，透明/浅色背景版本可直接叠在深色底上并加 20% 暗角。
- 录屏素材：`npm run dev` 后录 A2 时间轴自动播放（约 30 秒一圈）与 C2 视图切换。
- 节奏：A1 用条形生长，B1 用面板点亮，C1 用曲线擦除，D1 用上下镜头位移，避免四段都是静态图。
